# Offers & Lifecycle Playbook (No Heavy Discounting)

Use this when the user asks for **promotions**, **bundles**, **upsells**, **retention**, **loyalty**, or **email/SMS** strategy.

## Offer principles (margin-safe)

- Prefer **value-add** over % off:
  - free add-on (size upgrade, extra shot, syrup) where operationally safe
  - bundle pricing with controlled COGS (drink + do it )
  - priority pickup window / packaging upgrade (if real)
- Use **thresholds** carefully:
  - cart threshold that nudges AOV (only if fees/pricing are known and stable)
- Keep terms minimal and UI-friendly.
- Avoid “sitewide” or long-running discounts that train customers to wait.

## On-site placements (high leverage)

- **Menu/category page**: “Best with…” pairings (drink → pastry)
- **Product page**: size/add-on clarity + “Frequently ordered together”
- **Cart**: one-tap add-on upsell (fast, minimal)
- **Checkout**: reassurance copy (pickup/delivery timing, payment, support)

## Lifecycle flows (spec-first)

Only define flows that map to **real events** the product can track.

### 1) Welcome / first-order conversion

- Trigger: account created / email captured (whichever is real)
- Goal: first order within 48–72 hours
- Content: premium positioning + “start here” menu shortcut
- Incentive: value-add perk (not heavy discount), only if operationally supported

### 2) Abandoned cart (if cart state exists)

- Trigger: cart created + no checkout within X hours
- Goal: complete checkout
- Content: remind items + friction reducers (pickup vs delivery clarity)
- Incentive: only if necessary; prefer removing friction over discounting

### 3) Post-purchase repeat (2nd order)

- Trigger: order delivered/picked up
- Goal: repeat within 7–14 days
- Content: reorder convenience + “try next” suggestion based on category (not invented items)

### 4) Winback (lapsed)

- Trigger: no orders in 30/45/60 days (choose based on real cadence)
- Goal: return purchase
- Content: new/seasonal highlight (only if real) or a curated “premium favorites” set

## Copy patterns (premium/minimal)

- Lead with convenience and quality: “Ready for pickup”, “Brewed to order”, “Your usual, one tap away” (only if supported).
- Avoid loud urgency unless it’s truly limited: “Weekend-only”, “Today until 6pm”.
- Always include a short allergen note on food/pastry references where needed.
